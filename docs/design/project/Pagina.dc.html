Raft é um algoritmo de consenso pensado para ser fácil de entender. Ele separa o problema em três partes: [[Eleição de líder]], replicação de log e segurança.

Para revisar: no máximo um líder por termo; o líder só faz commit de entradas do próprio termo.

Eleição de líder

•Todo nó começa como seguidor e espera batimentos do líder.
•Sem batimento até o timeout, vira candidato, incrementa o termo e pede votos.
•Quem recebe a maioria dos votos vira líder do termo.

Comparar com Pesquisa · CAP e com o capítulo 9 do livro de dados intensivos: .

// candidato inicia a eleição
func (r *Raft) startElection() {
    r.term++
    r.votedFor = r.id
    for _, peer := range r.peers {
        go r.requestVote(peer, r.term)
    }
}

Se todos os seguidores expirassem juntos, todos virariam candidatos ao mesmo tempo e dividiriam os votos. Sortear o timeout entre 150 e 300 ms faz um nó quase sempre sair na frente.

Replicação de log

Líder

•Recebe comandos dos clientes.
•Envia AppendEntries em paralelo.
•Faz commit ao ter maioria.

Seguidores

•Só respondem ao líder.
•Rejeitam entradas de termos antigos.
•Aplicam o log em ordem.
