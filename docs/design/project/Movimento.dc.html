M1Movimento · implementaçãoP0

Tokens como variáveis CSS (--rapido, --entrada…) e espelhados no código JS para animações com mola. Com prefers-reduced-motion: reduce, os tokens são reescritos na raiz e cada coreografia troca deslocamento por opacidade. Interrompível: uma nova interação cancela a animação em curso a partir do estado atual, nunca espera terminar.
Controles da demonstração Câmera lenta é só para estudar a curva; não existe no produto.

01

Durações

Cinco tempos. Quanto maior a distância percorrida ou a mudança de contexto, maior o tempo. Hover e pressionar nunca passam de instante.

M2Durações · regraP0

Lento (300 ms) é o teto absoluto e fica reservado a mudanças de contexto: transição de página, elemento compartilhado, virar cartão. Mola é física, não tempo: rigidez 420, amortecimento 34, massa 1; o fallback CSS assenta em ~280 ms.
instante 80 ms
hover, pressionar, troca de cor
rápido 140 ms
menus, tooltips, check, toda saída
médio 220 ms
painéis, árvore, troca de view, toasts
lento 300 ms
página, elemento compartilhado, flip
mola ≈280 ms
soltar, levantar, materializar

02

Curvas

Quatro curvas. O que aparece desacelera ao chegar; o que sai acelera ao partir; o que se move dentro da tela usa a padrão. A mola tem um leve excesso, usado só onde há sensação física.

M3Curvas · onde usarP0

Trilhas desta seção rodam em lento para a diferença ficar visível. Nunca usar ease, linear ou ease-in-out padrão do navegador em componentes; linear só no brilho do skeleton e em progresso.
padrão
cubic-bezier(.2, 0, 0, 1)
movimento dentro da tela, reordenar, girar seta
entrada
cubic-bezier(0, 0, .2, 1)
o que aparece: menus, painéis, toasts
saída
cubic-bezier(.4, 0, 1, 1)
o que sai: fechar menus, dispensar toast
mola
cubic-bezier(.34, 1.56, .64, 1)
soltar ao arrastar, pop do check, cartão de ação
