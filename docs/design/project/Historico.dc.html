Consenso com Raft

Raft é um algoritmo de consenso pensado para ser fácil de entender. Ele separa o problema em três partes: eleição de líder, replicação de log e segurança.

Para revisar: no máximo um líder por termo; o líder só faz commit de entradas do próprio termo.

Eleição de líder

•Todo nó começa como seguidor e espera batimentos do líder.
•Depois de um tempo fixo Sem batimento até o timeout, vira candidato e pede votos.
•O nó com maior ID sempre vence.
•Quem recebe a maioria dos votos vira líder do termo.
